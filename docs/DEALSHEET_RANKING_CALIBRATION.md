# Deal sheet, ranking, what-if sliders, calibration loop, plan request pack

- **Deal Sheet PDF**: `GET /api/property/{id}/dealsheet.pdf?option_id=` (button on each layout option). Banners (screening tier, placeholders and which ones, mostly-allowances), all bed scenarios, compliance counts and deal-breakers, retrofit range or "total withheld: rates needed", economics with walk-away rent, break-even, sensitivity grid, latest Offer Builder run. Missing inputs print as "needs input".
- **Ranking** (Rank tab, `/api/ranking`): stabilised annual profit before rent per effort point, and per dollar of cash at risk, per confidence tier (never mixed). Effort = 1 + weighted sum of: parties (title type), retrofit scope, consent complexity, beds to fill. Weights are your assumptions (`config/effort_weights.yaml`, editable on the tab); the scales are a first guess to tune from real deals. Properties missing inputs are listed "not ranked" with what is missing. Cash at risk is blank until retrofit rates, pre-opening and working capital are all set.
- **What-if sliders** (option card): occupancy points, fee %, wage %, retrofit %. Not saved. The three-month delay is tested in the Offer Builder timeline, not in the sliders.
- **Calibration loop** (Quotes tab): enter real quotes or invoices per rate line; the tool shows each quote's unit rate against the model, how many quotes calibrate each line, and re-bases low/base/high as min/median/max of the quotes (written through My inputs, with history). One quote needs an explicit accept (no range). Percentage lines are not calibrated from line quotes.
- **Plan request pack** (Request plans button): owner/agent email draft (nothing is sent), Council LIM / property file guidance with the address and legal description pre-filled (LIM $387 standard / $522 urgent as found in a search summary on 2026-10-18; the property file fee and turnaround were NOT found; the pages were not opened), a request log with follow-up dates, and a site-visit form that writes to the Property Record at CONFIRMED (blanks never written).
